# 掛け算カード

家族で使える掛け算カードの静的Webアプリです。`index.html` がトップページです。

- 式をタップすると答えを表示／再タップで非表示
- 「次へ」「戻る」で問題履歴を移動
- 7種類の問題切り替え
- 問題数をリセット
- PWA対応。初回オンライン表示後、オフラインでも起動可能

## GitHub Pages で公開する

1. GitHubで **Public** リポジトリ `kakezan-card` を作成する。
2. このフォルダの中身をリポジトリのルートにアップロードする（ZIP自体はアップロードしない）。
3. リポジトリの **Settings → Pages** から `Deploy from a branch`、`main`、`/(root)` を選び **Save**。
4. `https://<ユーザー名>.github.io/kakezan-card/` でアクセスする。

※家計簿アプリの非公開リポジトリは変更しないでください。
